# 2026-09-16

## csharp3 教程全量 demo 修复（bookStudy）

用户反馈 /csharp3 的 demo 运行经常报错。排查发现正文所有 ```csharp 围栏（inlineCodeRun=true）都会送 /api/run-csharp 编译执行，共 565 段，其中 260 段编译失败。

### 根因（按数量）
1. CS8803：类型声明写在顶级语句之前（OOP 章节大量出现）
2. 局部函数不能重载（方法重载章节 CS0128）
3. 缺 using（System.Text / Reflection / Diagnostics / Text.Json.Nodes 等不在 ImplicitUsings 里）
4. JS 模板字符串吞反斜杠：`\d`→`d`、`\n`→真实换行、`'\''`→`'''`；部分章节整章写成单行 `\n` 转义风格
5. 语法错误：嵌套块注释、原始字符串引号数、params+命名参数、常量传播导致 switch 臂不可达(CS8510)
6. 运行时：Console.ReadLine/ReadKey（stdin 关闭→null/异常）、Console.Beep 平台不支持、GBK 编码不可用、/tmp 文件不存在/句柄冲突、Socket 连接拒绝
7. 依赖 NuGet（ILogger/Serilog/xUnit）或项目分文件片段：标记为 csharp-snippet（无运行按钮）

### 产出
- scripts/csharp3-fix-lib.mjs：模板字符串转义/围栏扫描/顶层成员切分工具库（unescapeRaw 按 JS 语义处理）
- scripts/verify-csharp3.mjs：全量编译+运行校验（6 并发 worker、进程组 kill、1MB 输出截断、增量落盘）
- scripts/fix-csharp3-phase1/2/3/4：类型后置 / 补 using / 重载进静态类 / using 前置
- app/api/run-csharp/route.js：runner 升级 v4，csproj 加 AllowUnsafeBlocks（unsafe 演示需要）
- 章节级说明：ch58(ILogger)、ch84/85(项目) 标注不可在线运行的原因

### 教训
- courses-data 里同文件存在两种代码块书写风格：多行直写 vs 单行 `\n` 转义，扫描工具必须两种都兼容
- 校验脚本要用编译产物直接 dotnet exec，dotnet run 会多一层子进程导致超时杀不干净

### 最终结果
- 534 段可运行代码全部通过编译 + 运行校验（verify15：0 失败）
- 31 段不可独立运行的片段标记为 csharp-snippet（NuGet 依赖 / 项目分文件 / 纯注释），并在 ch58/ch84/ch85 章节开头加了说明
- 端到端验证：POST /api/run-csharp 实测通过（含 unsafe 演示，runner v4 + AllowUnsafeBlocks 生效）
- package.json 新增 `npm run verify:csharp3`，后续改内容可一键回归
